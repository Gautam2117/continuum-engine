# Continuum creative skill routing

**Scope:** 48 independently authored channel identities, not 48 grouped template channels.

This route file is for **Codex/Claude creative development**. It does not itself implement new renderers, select runtimes inside the unattended Engine worker, or prove videos are production-ready.

When authoring a new channel scene, choose the channel from `docs/CHANNEL_SKILL_ROUTING.json`, read that channel's `autopilot/directors.py` contract and `autopilot/playbooks.py`, then load the `primary`, `secondary` and relevant QA skills from the verified local user skill roots. Do not substitute another channel's style, script, characters, geometry or branded scenes.

Render a representative 6–10-second sample. Inspect opening, middle, last, extreme camera, numeric labels, captions, foley, sound peaks and credited sources. A unit test is not a substitute for reviewing the actual MP4.

As of 14 November 2026, the authorized Mac has 85 pinned third-party agent skill instruction directories (68 previous plus 17 reviewed additions). They are optional documentation and helpers. Many need additional packages or artist-made assets. They are not 68 operational services and they do not run unless a coding agent explicitly loads them.

## Operating and licensing constraints

* Never copy competitor footage, characters, scripts, music, thumbnails or screenshots without rights.
* Do not run downloaded installation scripts without independent review. The local skills were pinned and copied without source execution.
* Only approved source evidence can support numeric labels or the narration. Ambiguous or conflicting numbers should block release.
* Remotion has separate commercial licensing; the associated agent guidance is not itself a production license.
* No paid service, provider key, cloud account, public upload or mass publish is implicitly authorized by any installed skill.
* The official YouTube originality and inauthentic-content rules still apply: animation automation alone is not monetization eligibility.
* The two gameplay channels, Felix and GOTZ, remain creator-led. Use the `video-edit` and `watch` skills only when their recordings are supplied; do not automate gameplay content creation.
